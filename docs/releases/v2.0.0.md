Margin 2.0 is the first stable release. Every edge and corner of the trackpad can now do what you want, and each app
can have its own layout. Your existing settings carry over, and the default layout works exactly as it did in 1.2.

## New

- **Edit any zone.** Click a zone in the menu's trackpad diagram to choose what it does. There are now eight zones: the
  left, right, top and bottom edges and all four corners.
- **Timer dial.** Set any edge to Timer, slide to pick 1 to 90 minutes and lift to start. The time left shows in the
  menu bar; when it ends the trackpad buzzes as a silent alarm (Gentle, Normal or Insistent), with an optional chime,
  notification, and Shortcuts to run on start and end. Corners can start a fixed-length timer, or pause or cancel one.
- **Hot corners on the trackpad.** Double-tap any corner to lock the screen, take a screenshot, open Mission Control or
  App Windows, show the desktop, start the screen saver, sleep the display, mute, launch an app or press a shortcut.
  Real clicks are told apart from taps, including a right-click corner.
- **More slide actions:** microphone level, undo and redo, switch tabs, switch Spaces and arrow keys, each with a haptic
  notch per step.
- **Flicks with any command.** The bottom-edge track skip is now a Flick, with a Forward and a Back command you can
  change and a Swap Directions button (it replaces Reverse Swipe).
- **Keystrokes and apps.** Record any keyboard shortcut, or pick any app to launch, including Safari.
- **App profiles.** Give the trackpad different actions while a chosen app is in front. The menu shows which profile is
  active. Profiles apply to trackpads; a Magic Mouse keeps the main layout.
- **Reset Layout** in Settings puts every zone back to the default.
- The level overlay now appears when a slide runs past 0% or 100%.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/abdullahabwisk/margin-mac-app/main/install.sh | bash
```

Or download **Margin-v2.0.0.zip** below. See the [README](https://github.com/abdullahabwisk/margin-mac-app#install) for
first-launch steps.

If you're updating and Margin is turned on in Accessibility but doesn't respond, click **Reset** in the menu and allow
access again. The install script does this for you.

Requires macOS 14 or later.
