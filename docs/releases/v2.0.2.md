Margin 2.0.2 has a new app icon.

## Changed

- **New app icon.** A space-grey trackpad on a light tile, with the brightness slider on its left edge and the volume
  slider on its right, the way Margin uses them. It sits on Apple's icon grid and fits in with the system apps in the
  Dock and Finder.

Nothing else changed since 2.0.1. Gestures still need fn or ⌥ unless you turn on **Settings → Use without Fn or Option
key**.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/abdullahabwisk/margin-mac-app/main/install.sh | bash
```

Or download **Margin-v2.0.2.zip** below. See the [README](https://github.com/abdullahabwisk/margin-mac-app#install) for
details.

If the Dock or Finder still shows the old icon after updating, quit and reopen Margin, or run `killall Dock`.

Requires macOS 14 or later.
